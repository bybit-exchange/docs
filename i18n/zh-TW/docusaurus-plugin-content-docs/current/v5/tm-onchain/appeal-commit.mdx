提交工單所需材料。同一工單在 `PENDING` / `REJECTED` 狀態下可提交，提交成功後進入 `COMMITTED`（審核中）狀態，**不可重複提交**。文件類材料需先通過 [文件上傳](./file-upload-sign) 拿到 `resourceId`。**每秒最多 10 次請求**


### HTTP請求
<APIEndpoint method="POST" url="/v5/compliance/appeal/commit" />

### 請求參數
| 參數 | 是否必需 | 類型 | 說明|
|:----- |:-------|:-----|------ |
|appealId |**true** |string |工單 ID |
|decisionType |false |integer |`0` = 正常提交（默認）；`1` = 拒絕提交，工單將被廢棄 |
|itemsData |**true** |array&lt;object&gt; |各材料的提交內容，每個材料一個元素 |
|> documentCode |**true** |string |材料編碼，與詳情接口返回的 `documentCode` 一致 |
|> resources |條件 |array&lt;object&gt; |文件資源列表，`styleBox` 為 `UPLOAD` / `MIXUPLOAD` 時使用 |
|>> resourceId |**true** |string |文件上傳成功後返回的資源 ID |
|>> [fileType](../enum#tm-onchain-filetype) |**true** |string |文件類型：`fiat-image` / `fiat-pdf` / `fiat-video` |
|> content |條件 |string |文本內容或單選值，`styleBox` 為 `INPUT` / `SINGLEINPUT` / `SELECT` / `RADIO` / `DATEPICKER` / `COUNTRYNAME` 時使用 |
|> mulContent |條件 |array&lt;string&gt; |多選值列表，`styleBox` 為 `CHECKBOX` 時使用 |
|> detailContent |條件 |string |選項的附加說明，所選選項要求補充說明時必填 |


### 響應參數
| 參數 | 類型 | 說明|
|:----- |:-----|----- |
|result |object |固定為空對象 `{}` |

---

```http
        {
            "documentCode": "OnchainAttachScreenshot",
            "resources": [
                {

        }

}
```
