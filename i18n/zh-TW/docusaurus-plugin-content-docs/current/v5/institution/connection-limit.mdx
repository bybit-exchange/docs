> API 限頻：每分鐘 1 次請求

:::info
此接口必須使用主帳戶 API key 請求。
:::

### HTTP 請求
<APIEndpoint method="GET" url="/v5/ins/connection-limit" />

### 請求參數
無

### 響應參數
| 參數 | 類型 | 說明 |
|:----- |:-----|----- |
|result |array |Object|
|> host |string |端點|
|> endpointDomain |string |專用端點域名|
|> spot |object |現貨連線限制|
|>> json |object |JSON WebSocket 連線限制|
|>>> max |integer |最大連線數|
|>>> current |integer |目前連線數|
|>> sbe |object |SBE 連線限制|
|>>> max |integer |最大連線數|
|>>> current |integer |目前連線數|
|> derivative |object |衍生品連線限制|
|>> json |object |JSON WebSocket 連線限制|
|>>> max |integer |最大連線數|
|>>> current |integer |目前連線數|
|>> sbe |object |SBE 連線限制|
|>>> max |integer |最大連線數|
|>>> current |integer |目前連線數|

### 請求範例

<Tabs groupId="programming-languages">
<TabItem value="http" label="HTTP">

```http
GET /v5/ins/connection-limit HTTP/1.1
Host: api.bybit.com
X-BAPI-SIGN: XXXXXXX
X-BAPI-API-KEY: xxxxxxxxxxxxxxxxxx
X-BAPI-TIMESTAMP: 1794457439807
X-BAPI-RECV-WINDOW: 5000
Content-Type: application/json
```

</TabItem>
</Tabs>
