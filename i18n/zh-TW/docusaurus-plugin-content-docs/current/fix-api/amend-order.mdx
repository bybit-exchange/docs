:::info important
- Bybit 使用 `AtomicReplaceRequest (XAR)` 進行委託修改。不支援 FIX 標準的 `OrderCancelReplaceRequest (G)`。
- 提供 `OrderID (37)` 或 `ClOrdID (11)` 其中之一來識別委託單。若兩者均提供且不一致，以 `OrderID` 為準。
- 僅包含需要修改的欄位，未填寫的欄位保持原值。
- 僅可修改**未成交**或**部分成交**的委託單。
:::

### 訊息類型

`AtomicReplaceRequest` — MsgType `XAR`

### 請求欄位

| Tag | 欄位 | 必填 | 類型 | 說明 |
|-----|-------|----------|------|-------------|
| 30010 | Category | **Y** | String | 產品類型，目前僅支援 `spot` |
| 55 | Symbol | **Y** | String | 交易對名稱，例如 `BTCUSDT`（大寫）|
| 37 | OrderID | N | String | 伺服器委託單 ID，`OrderID` 或 `ClOrdID` 至少填一個 |
| 11 | ClOrdID | N | String | 用戶端委託單 ID，`OrderID` 或 `ClOrdID` 至少填一個 |
| 38 | OrderQty | N | Qty | 新的委託數量 |
| 44 | Price | N | Price | 新的委託價格 |
| 99 | StopPx | N | Price | 條件委託的新觸發價格 |
| 30026 | TakeProfitPrice | N | Price | 新的止盈觸發價格 |
| 30027 | StopLossPrice | N | Price | 新的止損觸發價格 |
| 30030 | TpLimitPrice | N | Price | 新的止盈限價 |
| 30031 | SlLimitPrice | N | Price | 新的止損限價 |

### 回應

伺服器回應 **`OrderAmendAck (XAA)`**：

| Tag | 欄位 | 必填 | 說明 |
|-----|-------|----------|-------------|
| 37 | OrderID | N | 伺服器委託單 ID |
| 11 | ClOrdID | N | 用戶端委託單 ID |
| 150 | ExecType | **Y** | `5` = Replaced（成功）；`8` = Rejected |
| 39 | OrdStatus | **Y** | 目前委託狀態 |
| 103 | OrdRejReason | N | 拒絕原因代碼（`ExecType=8` 時）|
| 58 | Text | N | 錯誤訊息（`ExecType=8` 時）|

:::info
`OrderAmendAck` 僅包含最小狀態欄位，伺服器不會在修改回應中返回完整委託資訊（數量、價格等）。如需確認修改後的委託狀態，請透過後續的 `ExecutionReport` 推播（`ResponseMode=1` 時）或 REST API 查詢。
:::

---

### 請求範例

```
8=FIX.4.4|9=120|35=XAR|49=CLIENT|56=BYBIT|34=3|52=20240101-08:01:00.000|
30002=1704096060000|30001=5000|
30010=spot|55=BTCUSDT|37=1234567890123456|44=51000.00|10=xxx|
```

_注意：`|` 在實際傳輸格式中代表 SOH（0x01）字元。_

### 成功回應範例（已修改）

```
8=FIX.4.4|9=100|35=XAA|49=BYBIT|56=CLIENT|34=3|52=20240101-08:01:00.010|
30005=trace-def456|30007=120|30008=118|30009=1704096120000|
37=1234567890123456|150=5|39=0|10=xxx|
```

### 失敗回應範例（已拒絕）

```
8=FIX.4.4|9=110|35=XAA|49=BYBIT|56=CLIENT|34=3|52=20240101-08:01:00.010|
30005=trace-def457|30007=120|30008=118|30009=1704096120000|
37=1234567890123456|150=8|39=0|103=99|58=Order not found|10=xxx|
```
