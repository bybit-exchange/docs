`ExecutionReport (8)` 是 Bybit FIX API 的核心回應訊息，具有三種不同用途：

| 用途 | 觸發條件 | `ExecType` |
|------|---------|-----------|
| **委託確認（Order ACK）** | `NewOrderSingle (D)` 的直接回應 | `0`（New）或 `8`（Rejected）|
| **成交通知** | 委託成交（部分或全部）| `F`（Trade）|
| **委託狀態推播** | 被動委託狀態變更 | `4`、`5` 等 |

用途 2 與 3 僅在 `ResponseMode=1`（Everything）時推送。參見 [ResponseMode](../guide#responsemode)。

---

## 成交明細群組（NoFills）

僅在 `ExecType=F`（Trade）時存在，群組中每一條目代表一次個別成交。

`NoFills (30050)` 包含後續成交條目的數量。

| Tag | 欄位 | 說明 |
|-----|-------|-------------|
| 30051 | FillExecID | 執行 ID（`execId`）|
| 30052 | FillQty | 本次成交數量 |
| 30053 | FillPx | 成交價格 |
| 30054 | FillTime | 成交時間 |
| 30055 | FillCommission | 手續費金額 |
| 30056 | FillCommCurr | 手續費幣別 |
| 30059 | FillCommRate | 手續費率 |
| 30057 | FillValue | 成交金額 |
| 30058 | FillIsMaker | `Y` 表示此次成交為掛單方 |
| 30063 | FillExecType | `Trade` 或 `BlockTrade` |
| 30064 | FillLeavesQty | 本次成交後的剩餘數量 |
| 30065 | FillSeq | 用於跨訊息排序的跨序列號 |
| 30066 | FillBlockTradeId | 大宗交易 ID（如適用）|

當一筆委託同時產生多次成交（如掃過多個價位）時，`ExecutionReport` 包含單條訊息且 `NoFills > 1`。委託層級的 `CumQty (14)` 與 `AvgPx (6)` 反映群組內所有成交完成後的聚合狀態。

## 累計手續費群組（NoFeeDetails）

選填，提供委託層級按幣別的手續費彙總。

`NoFeeDetails (30060)` 包含手續費條目的數量。

| Tag | 欄位 | 說明 |
|-----|-------|-------------|
| 30061 | FeeCoin | 手續費幣別 |
| 30062 | Fee | 以此幣別計算的總手續費金額 |

## ExecType 值

| 值 | 名稱 | 說明 |
|-------|------|-------------|
| `0` | New | 委託已接受並在掛單簿等待 |
| `4` | Canceled | 委託已取消 |
| `5` | Replaced | 改單事件。改單受理後由此類型的 `ExecutionReport` 推送最終訂單狀態；OrdStatus 仍為 `0`（New）——UTA 的 OrdStatus 不包含 Replaced 值 |
| `6` | PendingCancel | 取消中。不會透過 `ExecutionReport` 推送——取消請求由 `OrderCancelAck (XCA)` 確認收到。|
| `8` | Rejected | 委託或請求被拒絕 |
| `A` | PendingNew | 新委託的過渡狀態。`OnlyAcks` 模式下，`NewOrderSingle` 一定會先返回 `PendingNew`，再返回最終的 `New` 或 `Rejected`。`Everything` 模式下，`PendingNew` 與 `New` 均會推送，但可能亂序到達。|
| `D` | Deactivated | 條件委託已停用 |
| `E` | PendingReplace | 修改中。不會透過 `ExecutionReport` 推送——修改請求由 `OrderAmendAck (XAA)` 確認收到；修改後的訂單狀態由 `ExecType=5`（Replaced）的 `ExecutionReport` 推送給出（該推送中 `OrdStatus` 仍為 `0` New，UTA 的 OrdStatus 不包含 Replaced 值）|
| `F` | Trade | 委託成交（部分或全部）|
| `T` | Triggered | 條件委託已觸發 |
| `U` | Untriggered | 條件委託等待觸發 |

---

## OrdStatus 值

| 值 | 名稱 | 說明 |
|-------|------|-------------|
| `0` | New | 有效，未成交 |
| `1` | PartiallyFilled | 部分成交，仍有效 |
| `2` | Filled | 全部成交 |
| `4` | Canceled | 已取消 |
| `6` | PendingCancel | 取消請求處理中 |
| `8` | Rejected | 已拒絕 |
| `A` | PendingNew | 委託提交處理中 |
| `D` | Deactivated | 條件委託已停用 |
| `E` | PendingReplace | 修改請求處理中 |
| `F` | PartiallyFilledCanceled | 部分成交後取消 |
| `T` | Triggered | 條件委託已觸發 |
| `U` | Untriggered | 條件委託等待觸發 |
