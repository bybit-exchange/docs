## Set Trade Auto Repay



Enable or disable automatic repayment after an eligible spot trade credits a coin to the Unified account. The credited coin can repay its own flexible-rate liability without asset conversion. Trade auto repayment runs only in Cross and Portfolio margin modes; the setting has no effect in Isolated mode. This setting is separate from scheduled auto repayment configured through `set-auto-repay-mode`, and is disabled by default.
