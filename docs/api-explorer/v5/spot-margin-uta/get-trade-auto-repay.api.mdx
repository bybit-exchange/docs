## Get Trade Auto Repay



Retrieve the authenticated Unified account's trade auto repayment switch. The saved setting takes effect only in Cross and Portfolio margin modes; it has no effect in Isolated mode. This switch is separate from the scheduled auto repayment settings returned by `get-auto-repay-mode`.
