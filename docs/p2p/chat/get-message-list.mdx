### HTTP Request
POST `/v5/p2p/chat/message/listpage_v1`

### Request Parameters
| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------ |
|lastId|**true** |integer |Cursor for pagination. Pass `0` to query from the latest message |
|limit|**true** |integer |Page size, max is 30 |
|sessionId|**true** |string |Session ID, AES encrypted |

### Response Parameters
| Parameter | Type | Comments|
|:----- |:-----|----- |
|messages |array&lt;object&gt; |Message list, ordered by create time desc |
|> id |integer |Message ID, used as cursor for next page |
|> sendUserNickName |string |Sender's nickname |
|> contentType |string |Message type <ul><li>`str`: text</li><li>`pic`: image</li><li>`pdf`: PDF</li><li>`video`: video</li></ul>|
|> message |string |Message content, JSON string containing `content`, `msgCode`, `msgType`, `fileName`, `size` |
|> createDate |integer |Message create time, timestamp ms |
