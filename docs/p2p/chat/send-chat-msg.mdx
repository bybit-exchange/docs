### HTTP Request
POST `/v5/p2p/chat/message/send_v1`

### Request Parameters
| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------ |
|message|**true** |string |Chat message content. Max length 1000 characters |
|contentType|**true** |string |Message type <ul><li>`str`: text</li><li>`pic`: image</li><li>`pdf`: PDF</li><li>`video`: video</li></ul>|
|sessionId|**true** |string |Session ID, AES encrypted, obtained from Get Session ID |
|orderId|**true** |string |Order ID, used to validate order parties |

### Response Parameters
None
