### HTTP Request
POST `/v5/p2p/chat/session/list_v1`

### Request Parameters
| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------ |
|lastId|**true** |integer |Cursor for pagination. Pass `0` for the first page |
|size|**true** |integer |Page size |
|readStatus|**true** |integer |Read status filter <ul><li>`0`: unread</li><li>`1`: read</li><li>`2`: all</li></ul>|
|type|false |string |Session type <ul><li>`GROUP`: group chat</li><li>`SINGLE`: single chat</li></ul>|

### Response Parameters
| Parameter | Type | Comments|
|:----- |:-----|----- |
|chatSession |array&lt;object&gt; |Session list |
|> sessionName |string |Session name, counterparty nickname |
|> sessionId |string |Session ID, AES encrypted |
|> type |string |Session type, `SINGLE`: single chat |
|> id |integer |Record ID, used as cursor for next page |
|> unreadCount |integer |Unread message count |
