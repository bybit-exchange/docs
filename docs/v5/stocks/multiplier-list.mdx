Query the historical / latest `multiplier` values applied to mStocks Tokens, paged.

:::info
This endpoint is only available for Market Maker.
:::

### HTTP Request
<APIEndpoint method="GET" url="/v5/rwa/stocks/market/getMultiplierList" />

### Request Parameters
| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------ |
|symbol |false |string |Stock symbol, e.g. `AAPL-US`. Filter by symbol; returns all symbols if omitted |
|current |**true** |integer |Current page number |
|pageSize |**true** |integer |Page size. Default `10` |

### Response Parameters
| Parameter | Type | Comments|
|:----- |:-----|----- |
|current |integer |Current page number |
|pageSize |integer |Page size |
|total |integer |Total number of records |
|list |array&lt;object&gt; |List of multiplier records |
|> mstockSymbol |string |mStocks Token symbol, e.g. `AAPLM` |
|> multiplier |string |Currently effective conversion ratio |
|> effectiveTime |integer |Latest effective time (epoch ms). `0` means the initial multiplier |
