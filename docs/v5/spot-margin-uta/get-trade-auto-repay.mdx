Retrieve the authenticated Unified account's trade auto repayment switch.

:::info
This saved setting applies only to Cross and Portfolio margin modes. It has no effect in Isolated mode. It is separate from the scheduled automatic repayment settings returned by [Get Auto Repay Mode](get-auto-repay-mode).
:::

### HTTP Request
<APIEndpoint method="GET" url="/v5/spot-margin-trade/get-trade-auto-repay" />

### Request Parameters
None.

---

### Response Parameters
| Parameter | Type | Comments |
|:----- |:-----|----- |
|autoRepay |string |Saved switch state. `1`: enabled; `0`: disabled. |
