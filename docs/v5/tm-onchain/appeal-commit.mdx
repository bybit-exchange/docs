Submit the required materials for an appeal. The same appeal can be committed while in `PENDING` / `REJECTED` status; after a successful commit it moves to `COMMITTED` (under review) and **cannot be re-committed**. File materials must first go through the [file upload flow](./file-upload-sign) to obtain a `resourceId`. **Up to 10 requests per second**


### HTTP Request
<APIEndpoint method="POST" url="/v5/compliance/appeal/commit" />

### Request Parameters
| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------ |
|appealId |**true** |string |Appeal ID |
|decisionType |false |integer |`0` = normal submit (default); `1` = refuse submit, appeal will be disused |
|itemsData |**true** |array&lt;object&gt; |Submission content per material, one element per material |
|> documentCode |**true** |string |Material code, must match the `documentCode` returned by the detail endpoint |
|> resources |Conditional |array&lt;object&gt; |File resource list, used when `styleBox` is `UPLOAD` / `MIXUPLOAD` |
|>> resourceId |**true** |string |Resource ID returned after a successful file upload |
|>> [fileType](../enum#tm-onchain-filetype) |**true** |string |File type: `fiat-image` / `fiat-pdf` / `fiat-video` |
|> content |Conditional |string |Text or single-selection value, used when `styleBox` is `INPUT` / `SINGLEINPUT` / `SELECT` / `RADIO` / `DATEPICKER` / `COUNTRYNAME` |
|> mulContent |Conditional |array&lt;string&gt; |Multi-selection values, used when `styleBox` is `CHECKBOX` |
|> detailContent |Conditional |string |Additional explanation for the selected option; required when the chosen option asks for supplementary details |


### Response Parameters
| Parameter | Type | Comments|
|:----- |:-----|----- |
|result |object |Always an empty object `{}` |
